# v50-to-v40
Reverts SystemUX to v40's on v50

## NOT COMPATIBLE WITH ANY VERSION PAST v50

If your interested in custom roms on unlockable Oculus headsets feel free to join https://discord.gg/u67FFUk6zs

# Instructions
 1.  Download and extract the zip from releases
 2.  Install [CorePatch](https://github.com/LSPosed/CorePatch/releases) and [Vector](https://github.com/JingMatrix/Vector)
 3. In Vector click on CorePatch and check system_server then Soft reboot
 4. Open CorePatch (app) and enable Bypass downgrade and Bypass verification 
 5.  Finally run the installer and your done!
